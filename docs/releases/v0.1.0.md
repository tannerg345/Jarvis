## Stage 0 — Foundation

JARVIS now runs on your Mac: a menu bar icon, a main window, the Option + Space command bar, reminders, the daily briefing, and start at login.

### Install

1. Download `JARVIS.zip` below and double-click it.
2. Drag **JARVIS** into **Applications**.
3. First open only: right-click JARVIS → **Open** → **Open** (or System Settings → Privacy & Security → **Open Anyway**).
4. Allow notifications when asked.

### Please test

- [ ] The app opens on today's briefing ("Good morning, sir." or afternoon/evening).
- [ ] The ✨ icon appears in the menu bar and its panel opens.
- [ ] **Option + Space** opens the command bar from any app; Esc closes it.
- [ ] `help` lists what JARVIS can do.
- [ ] `remind me to stretch in 1 minute` confirms, then a notification arrives about a minute later.
- [ ] `remind me at 5pm to go to the gym` appears under Upcoming reminders; the ✕ cancels it.
- [ ] `open fitness`, `show calendar` and `settings` open the right place.
- [ ] Quit (menu bar → Quit JARVIS) and reopen: reminders are still listed, and the briefing does not show again today.
- [ ] Restart the Mac: JARVIS starts on its own (approve it in System Settings → General → Login Items if asked).

Tell me anything that looks wrong, feels slow, or doesn't work.
